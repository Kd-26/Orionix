# Control Plane

**Purpose:** one modular future cloud coordination deployable. **Responsibilities:** module boundaries for organizations/memberships, projects, agents, optimization jobs/attempts, append-only state events, experiments/benchmarks/candidates, capsules, schedules, and audit events. **Non-responsibilities:** GPU/engine execution, a production API today, authentication, billing, queues, or database selection. **Allowed dependencies:** common, config, domain, schemas, and feature ports. **Prohibited dependencies:** GPU libraries, engine/provider execution SDKs, customer data, and web UI internals. **Status:** package/documentation boundary only. **Next milestone:** define persistence and tenant-authorization ports inside this single service.

Future APIs use explicit `/v1` contracts, tenant authorization on every resource, idempotent job creation/result submission, explicit transitions, cursor pagination, stable identifiers, backward-compatible schema changes, at-least-once command delivery, leases, and reconciliation.
