# Documentation

- `architecture/` describes boundaries, data flow, and the Execution Capsule concept.
- `development/` defines developer workflow and engineering policy.
- `operations/` records launch gates and future runbook requirements.
- `security/` records the customer-infrastructure security baseline.
- `adr/` records durable architecture decisions.

Product scope and the unimplemented certification target are recorded in `product-scope.md` and `supported-matrix.md`.

Documentation describes intended boundaries; future capabilities are not claims of implementation.
