# Execution Capsule

**Purpose:** metadata definitions for a future reusable deployment artifact. **Responsibilities:** versioned manifest, compatibility, workload/SLO/quality assumptions, evidence references, artifact descriptors, policy/export metadata, and integrity metadata. **Non-responsibilities:** binary packing/extraction, signing, CUDA graph restoration, memory reconstruction, deployment, or Foundry behavior. **Allowed dependencies:** `common`, `domain`, `schemas`, Pydantic, and the standard library. **Prohibited dependencies:** integrations, engine/provider SDKs, CUDA, web frameworks, and ORMs. **Status:** manifest schema `2.0` only. **Next milestone:** define canonical serialization, trust, and safe extraction rules before payload work.
