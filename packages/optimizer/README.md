# Optimizer

**Purpose:** ports for future configuration planning and selection. **Responsibilities:** interfaces for candidate generation, strategies, constraints, and ranking. **Non-responsibilities:** inference execution, benchmarking, Optuna/Bayesian search, quality evaluation, persistence, or engine APIs. **Allowed dependencies:** `domain` and `schemas`. **Future:** capability detection, rule-based search reduction, Pareto optimization, and historical prediction will be added behind these boundaries only when requirements are concrete.
