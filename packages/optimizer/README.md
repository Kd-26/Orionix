# Optimizer

**Purpose:** ports for future configuration planning and selection. **Responsibilities:** capability evaluation, candidate generation, strategy, constraint evaluation, and result ranking interfaces. **Non-responsibilities:** inference execution, real benchmarking, Optuna/Bayesian search, quality inference, persistence, or engine APIs. **Allowed dependencies:** `schemas` and the standard library. **Prohibited dependencies:** integrations, agent/services, engine/provider SDKs, CUDA, web frameworks, and ORMs. **Status:** protocols only. **Next milestone:** defer algorithms until benchmark observations and persistence are real.
