# Domain

**Purpose:** stable business concepts shared across Orionix. **Responsibilities:** optimization-job, compute-target, and capsule lifecycle enums; compatibility re-exports for common identifiers. **Non-responsibilities:** serialized envelopes, persistence, optimization logic, discovery, or integrations. **Allowed dependencies:** `common` and the standard library. **Prohibited dependencies:** Pydantic, engine/provider SDKs, CUDA, web frameworks, ORMs, and outer packages. **Status:** state enums are implemented; no transition behavior exists. **Next milestone:** define allowed state-transition policy beside control-plane persistence without embedding orchestration here.
