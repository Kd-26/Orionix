# Benchmark

**Purpose:** engine-neutral benchmark planning and execution boundaries. **Responsibilities:** versioned plan/run/environment contracts and a runner protocol for normalized observations. **Non-responsibilities:** launching engines, load generation today, GPU measurement, CUDA access, cost lookup, or fabricated results. **Allowed dependencies:** `common`, `schemas`, Pydantic, and the standard library. **Prohibited dependencies:** engine/provider SDKs, CUDA, control-plane/web modules, and ORMs. **Status:** contracts and protocol only; metric definitions live in architecture docs. **Next milestone:** implement a deterministic local HTTP load generator against a separately supervised fake server before vLLM.
