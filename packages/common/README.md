# Common

**Purpose:** genuinely cross-cutting primitives. **Responsibilities:** typed identifiers, base errors, correlation context, structured-log formatting, and credential-pattern redaction. **Non-responsibilities:** configuration loading, domain concepts, vendor adapters, business logic, telemetry export, or secret retrieval. **Allowed dependencies:** Python standard library only. **Prohibited dependencies:** every other Orionix package, Pydantic, engine/provider SDKs, CUDA, web frameworks, and ORMs. **Status:** identifiers, error hierarchy, and safe logging helpers are implemented. **Next milestone:** add an injectable clock only when lease/state-transition code requires one.
