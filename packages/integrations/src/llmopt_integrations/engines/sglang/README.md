# SGLang engine adapter

**Purpose:** reserve a later SGLang adapter. **Responsibilities:** eventually validate SGLang-compatible contracts and build typed launch specifications. **Non-responsibilities:** provisioning, optimization, or exposing SGLang objects. **Allowed dependencies:** stable contracts and a future optional SGLang extra. **Prohibited dependencies:** control-plane, provider SDKs, and unrelated engines. **Status:** namespace only. **Next milestone:** none before vLLM certification.
