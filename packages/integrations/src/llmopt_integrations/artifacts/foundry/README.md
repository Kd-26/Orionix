# Foundry artifact boundary

Foundry may later be evaluated, after license/security review, as an Apache-2.0 internal primitive for CUDA graph persistence, deterministic memory reconstruction, kernel binary restoration, and graph-template reconstruction. Only capsule/agent composition may use a future adapter. Foundry APIs, binaries, CUDA handles, and methodology must not leak into stable contracts or unrelated packages. Status: no source, installation, SAVE/LOAD behavior, or implementation. Next milestone: none before capsule integrity and compatibility semantics are approved.
