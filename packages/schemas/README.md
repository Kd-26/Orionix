# Schemas

**Purpose:** versioned, serialization-safe contracts between subsystems. **Responsibilities:** model, hardware, workload, SLO, quality, serving, benchmark, optimization, agent commands, execution/provisioning, diagnostics, deployment, and compatibility metadata. **Non-responsibilities:** discovery, execution, ranking, persistence, networking, or vendor translation. **Allowed dependencies:** `common`, `domain`, Pydantic, and the standard library. **Prohibited dependencies:** feature packages, integrations, agents/services, engine/provider SDKs, CUDA, web frameworks, and ORMs. **Status:** milestone contracts and schema versions are implemented. **Next milestone:** freeze `/v1` serialization examples and a compatibility-change policy before persistence/API work.
