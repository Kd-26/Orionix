# Telemetry

**Purpose:** an explicit, no-op-by-default metrics boundary. **Responsibilities:** distinguish control-plane product telemetry, benchmark measurements, customer inference metrics, and agent/system health. **Non-responsibilities:** external transmission, Prometheus endpoints, OpenTelemetry exporters, Grafana dashboards, or tracing. **Allowed dependencies:** standard library only. **Prohibited dependencies:** every other Orionix package, exporters, engine/provider SDKs, CUDA, and web/ORM libraries. **Status:** metric types, sink protocol, and no-op sink are implemented; nothing is transmitted. **Next milestone:** add an in-process test sink when real agent/control-plane behavior emits metrics.
