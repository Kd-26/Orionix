# CLI

**Purpose:** human-facing entry point for local and future control-plane workflows. **Responsibilities:** safe command registration, help, argument validation, and later composition through ports. **Non-responsibilities:** optimization algorithms, provider provisioning, engine/GPU execution, persistence, or domain logic. **Allowed dependencies:** `common`, `config`, and application interfaces as needed. **Prohibited dependencies:** concrete engine/provider adapters in command modules, CUDA, ORMs, and web frameworks. **Status:** all planned command names and help are registered; execution returns one consistent milestone message. **Next milestone:** wire one CPU-safe local `inspect` vertical slice through discovery interfaces.
